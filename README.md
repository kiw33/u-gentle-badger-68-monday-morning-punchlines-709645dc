make.fun entry for [Monday Morning Punchlines](https://make.fun/competitions/u-gentle-badger-68-monday-morning-punchlines-709645dc) — $5.

## Entry

`main.py` (Python 3.13, harness program/v1) writes one joke about Monday
mornings to `/output/entry.txt`:

> My alarm clock requested weekends off — it says waking me on Monday counts as workplace harassment.

(99 characters; gate: 1-200 characters, UTF-8, single line.)

## How it works

No network, no randomness, no input — the program writes a fixed string, so
every run produces byte-identical output. See `BUILD-NOTE.md` for the
verification evidence.
